# Evaluación Sumativa 1 Programación Backend
La empresa EcoEnergy ofrece un sistema web para PYMEs que desean monitorear su consumo energético.
Cada empresa que contrata el servicio debe poder registrarse en la plataforma y luego iniciar sesión para acceder a un Dashboard inicial, donde visualizará:
* Últimas 10 mediciones de consumo.
* Zonas con su cantidad de dispositivos.
* Alertas generadas en la semana, clasificadas en: Grave, Alta, Media.

Además, el sistema debe permitir:
* Listar todos los dispositivos, con filtro por categoría.
* Ver el detalle de un dispositivo con sus mediciones y alertas.
* Listar todas las mediciones con su dispositivo asociado.

En caso de que una empresa olvide su contraseña, el sistema debe contar con una funcionalidad de recuperación de acceso para garantizar la continuidad del servicio.

**Cada entidad (Dispositivo, Medición, Zona, Alerta, etc.) debe estar relacionada con la PYME que contrató el servicio.**
